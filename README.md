## 🌟 رؤية المشروع وفكرته

تطبيق **«سَمَر»** هو مرشد سياحي وراوٍ إلكتروني مبتكر يُحيي التراث السعودي العريق للزوار والمستكشفين. يدمج التطبيق بين **أحدث تقنيات الذكاء الاصطناعي التوليدي والبصري (Gemini AI & Vision)** وبين **الهوية الوطنية والحس الثقافي السعودي الأصيل** باللهجة النجدية الودودة.

هدفنا هو تحويل زيارة المعالم التاريخية من مجرد مشاهدة عابرة إلى **تجربة تفاعلية حيّة**، تمكّن السائح من التحدث مع المكان، التعرف على نقوشه المعمارية بالتقاط الصور، وحل التحديات التراثية بكل يسر وسهولة.

## 🔥 أهم الميزات والابتكارات (Key Features)

### 🤖 1. راوي المكان الذكي (Samar AI Persona)
- **الردود النجدية الأصيلة:** يتحدث «سَمَر» بأسلوب سعودي نجدي ودود ومحترم بعيداً عن الجفاف واللغة الآلية المصطنعة.
- **قواعد الردود الاجتماعية الثابتة:** محرك ذكي يتيح الرد الفوري المباشر على أكثر من 12 حالة من التحايا والترحيب والشكر دون الانتظار.
- **الردود الصوتية والنصية:** إمكانية الاستماع للقصص التراثية أو المحادثة النصية والمباشرة.

### 📸 2. التعرف البصري المعماري (Gemini Vision AI)
- **تحليل النقوش والمعالم:** بمجرد التقاط السائح صورة لأي معلم (مثل قصر الفريد بالعلا، حي الطريف بالدرعية، قصر المصمك، جدة التاريخية، الأحساء، تاروت)، يتعرف الذكاء الاصطناعي على الطراز المعماري ونوع الأحجار والنقوش.
- **بطاقة معالِم شاملة:** يُعيد التطبيق ناتجاً موثقاً يتضمن: اسم المعلم، الموقع، نسبة الثقة، الفترة الزمنية، التصنيف، الوصف التاريخي، ومعلومة ممتعة فريدة.
- **مكافأة الاستكشاف:** يمنح المستخدم **+100 نقطة استكشاف** فورية عند التوثيق البصري لكل معلم.

### 🔊 3. نمط سَمَر الشامل للمكفوفين (Blind Mode & Screen Reader)
- **ابتكار شمولية الوصول (Accessibility):** تم تصميم وضع مخصص بالكامل للمكفوفين وضعاف البصر يعمل بنفس آلية قارئ الشاشة في الهواتف الذكية:
  - **اللمسة الأولى:** تحديد العنصر وقراءة اسمه ووظيفته بصوت واضح (مثل: *"ابدأ الرحلة، زر"*، *"حي الطريف، معلم تاريخي"*).
  - **اللمسة المزدوجة (Double Tap):** تنفيذ الإجراء أو الانتقال بشكل دقيق وسلس.
  - **إطار تركيز عالي التباين (#f59e0b)** وتنقل بلوحة المفاتيح.

### 📍 4. خريطة تفاعلية ومحرك تحديد أقرب معلم (GPS Distance Engine)
- **حساب المسافات الحقيقية (Haversine Algorithm):** يحسب المسافة بين موقع السائح الحالي بالـ GPS وكافة المعالم السعودية بالكيلومترات (KM).
- **أقرب معلم إليك (Nearest Landmark Banner):** يُبرز تلقائياً أقرب معلم تراثي للمستخدم مع إمكانية إطلاق الجولة الصوتية فوراً.
- **خصوصية وأمان 100%:** تمت معالجة بيانات الموقع محلياً على جهاز المستخدم دون مشاركتها خارجياً.

### 🎮 5. نظام التحديات التراثية والتدرج (Gamification System)
- **أسئلة تراثية تفاعلية:** أسئلة خيارات متعددة (A, B, C, D) عن تفاصيل المعالم النجدية والحضارية.
- **شارات وإنجازات (Badges):** فتح شارات استكشاف مخصصة لكل موقع وتحديث رصيد النقاط والمستوى الشخصي تلقائياً.
- **ملف شخصي مخصص:** إمكانية كتابة الاسم وتعديله بحرية، والبدء برصيد مستكشف جديد يتدرج مع كل إنجاز.

## 🏛️ التوثيق والمصادر الرسمية (Official Saudi Sources)

تم بناء وتغذية المحرك المعرفي لتطبيق **«سَمَر»** استناداً إلى البيانات والتوثيقات الصادرة من الهيئات الرسمية المعنية بالتراث والسياحة في المملكة العربية السعودية:

| الهيئة الرسمية | نطاق التوثيق والمعالم |
|---|---|
| 🏛️ **هيئة التراث (وزارة الثقافة)** | قصر المصمك، قصر إبراهيم، قلعة تاروت، التراث العمراني |
| 🌿 **الهيئة الملكية لمحافظة العلا** | موقع الحِجر (مدائن صالح)، قصر الفريد، جبل الفيل |
| 🏰 **هيئة تطوير بوابة الدرعية** | حي الطريف التراثي، قصر سلوى، وادي حنيفة |
| 🌊 **برنامج جدة التاريخية** | حي البلد، الرواشين الخشبية، المباني المرجانية |
| 🌴 **روح السعودية (الهيئة السعودية للسياحة)** | واحة الأحساء، جبل القارة، المسارات السياحية |

## 💻 البنية التقنية (Tech Stack)

```
SAMAR Heritage App Architecture
├── Front-End: React 18 / TanStack Start (SSR & File-based Routing)
├── Styling: Vanilla CSS Tokens & TailwindCSS (Custom Najdi Sand Palette)
├── AI Vision Engine: Google Gemini 1.5 Flash Vision API
├── Text AI Engine: Google Gemini 1.5 Flash + Saudi Social Rules Engine
├── Audio Engine: Browser Native SpeechSynthesisUtterance (ar-SA) + Web Audio FX
├── Geolocation: HTML5 Geolocation API + Haversine Formula (Local & Private)
└── Production Deployment: Netlify Production SSR + Custom Manifest Patch
```

## 🛠️ كيفية التشغيل محلياً (Local Setup)

```bash
# 1. استنسخ المستودع
git clone https://github.com/shahadmaalanazi/samar.git
cd samar

# 2. ثبّت الحزم والاعتماديات
npm install

# 3. أنشئ ملف البيئة .env.local وضف مفتاح Gemini
GEMINI_API_KEY=your_gemini_api_key_here

# 4. شغّل سيرفر التطوير المحلي
npm run dev

# 5. للبناء والتحقق من الإنتاج
npm run build
```
